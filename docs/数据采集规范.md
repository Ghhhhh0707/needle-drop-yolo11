# 数据采集规范

## 1. 拍摄设备
- 智能手机（记录型号进台账）
- 固定焦距，关闭美颜/滤镜

## 2. 拍摄点位
- 位置：横机出料口照灯前
- 距离：距布料下落垂直面正前方约 **50cm**
- 角度：光轴垂直布面

## 3. 拍摄内容
- **正样本**：有明显漏针/破洞的织物
- 兼顾两种场景：手持织补操作、纯织物特写

## 4. 颜色覆盖
- 主色：**红、绿、蓝、黑、白** 五种
- 每种颜色需覆盖不同批次、不同光照
- 当前重点补采：绿色、蓝色

## 5. 命名规范
- 格式：`微信图片_YYYYMMDDHHMMSS_序号_批次号.jpg`
- 示例：`微信图片_20260920142725_188_28.jpg`
- 同一漏针样本不要连拍多张（去重会删除近似重复）

## 6. 台账记录
每次采集后更新 `采集记录.csv`：
| 字段 | 说明 |
|---|---|
| 文件名 | 图片文件名 |
| 批次 | 采集批次号 |
| 颜色 | 织物主色 |
| 采集人 | 姓名 |
| 日期 | 采集日期 |
| 手机型号 | 拍摄设备 |
| 横机型号 | 车间设备 |
| 备注 | 特殊说明 |
