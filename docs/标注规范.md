# 标注规范

## 1. 标注方式
- 当前阶段：微信/画图工具手动红圈圈出漏针/破洞区域
- 目标格式：YOLO TXT（`class x_center y_center width height`）

## 2. 类别定义
- **方案A（当前推荐）**：单类别 `defect`（class_id=0）
  - 包含：破洞、脱线、纱线松散外翻等所有漏针表现
- **方案B（待决策）**：双类别
  - `hole`（破洞）/ `loose_yarn`（脱线/纱线松散）
  - 启用条件：每类样本 ≥ 100 张

## 3. 画圈要求
- 红圈应**紧密包围**缺陷区域，圈住所有松散纱线
- 圈可略大于缺陷本身，但不宜过大包含正常纹理
- 多个独立缺陷需分别画圈

## 4. 导出校验
- 运行 `scripts/export_annotations.py` 自动生成 YOLO TXT
- 生成 `visualize/` 预览图，人工抽检 10%
- 抽检重点：圈是否偏位、是否漏圈、是否多圈

## 5. 常见问题
| 问题 | 解决 |
|---|---|
| 红圈贴边导致坐标越界 | `validate_dataset.py` 自动裁剪回 [0,1] |
| 圈图层与原图分辨率不一致 | 先缩放对齐再导出 |
| 同一缺陷被圈多次 | 去重后合并为一个框 |
